## 🚀 2. Điểm nổi bật & Tính năng chuyên sâu

### 2.1. Cơ sở dữ liệu chuẩn GDPT 2018 đầy đủ 39 chương
- **15 chương môn Vật lí** (Lớp 10, 11, 12): Mở đầu, Động học, Động lực học, Năng lượng, Động lượng, Chuyển động tròn, Biến dạng, Dao động, Sóng, Điện trường, Dòng điện không đổi, Từ trường, Nhiệt học, Khí lí tưởng, Vật lí hạt nhân.
- **24 chương môn Toán** (Lớp 10, 11, 12): Mệnh đề - Tập hợp, Bất phương trình, Hệ thức lượng, Vectơ, Thống kê, Hàm số, Đại số tổ hợp, Tọa độ Oxy, Dãy số, Giới hạn, Hàm mũ - Logarit, Quan hệ vuông góc, Xác suất, Khảo sát hàm số, Vectơ Oxyz, v.v.
- Tích hợp 4 bộ sách giáo khoa: **Kết nối tri thức với cuộc sống (KNTT)**, **Chân trời sáng tạo (CTST)**, **Cánh Diều (CD)** và **Chương trình chung chuẩn Bộ**.
- Tự do bổ sung thêm YCCĐ thủ công, chỉnh sửa câu chữ hoặc xóa YCCĐ theo thực tế giảng dạy.

### 2.2. Quy trình làm việc 6 bước mượt mà (6-Step Stepper)
1. **Bước 1: Khai báo đề:** Môn, Lớp, Học kì (HK1, HK2, Cả năm), Loại đề (Giữa kì, Cuối kì, Thường xuyên), Trường, Tổ bộ môn, Thời gian làm bài, Điểm tối đa.
2. **Bước 2: Phạm vi kiến thức:** Bộ lọc tích chọn nhanh hoặc bỏ chọn từng chương, từng bài học cần đưa vào kì kiểm tra.
3. **Bước 3: Chọn YCCĐ:** Hiển thị danh mục YCCĐ phân theo 3 mức độ (Nhận biết, Thông hiểu, Vận dụng) với mã định danh chuẩn.
4. **Bước 4: Cấu trúc đề & Tỉ lệ điểm:**
   - 3 Preset chuẩn mực:
     - `thpt_toan` (Cấu trúc Đề thi TN THPT môn Toán từ 2025: 12 câu TN nhiều phương án [3đ] + 4 câu TN đúng/sai [4đ = 16 lệnh] + 6 câu TN trả lời ngắn [3đ]).
     - `thpt_ly` (Cấu trúc Đề thi TN THPT môn Vật lí từ 2025: 18 câu TN nhiều phương án [4.5đ] + 4 câu TN đúng/sai [4đ = 16 lệnh] + 6 câu TN trả lời ngắn [1.5đ]).
     - `kt_dinh_ky` (Trắc nghiệm nhiều lựa chọn + Tự luận truyền thống).
   - Tự do thêm phần Tự luận (Essay) với cấu trúc số ý $1a, 1b...$ tùy biến.
   - Thiết lập tỉ lệ mục tiêu nhận thức (ví dụ: $40\% : 30\% : 30\%$).
5. **Bước 5: Phân bổ câu hỏi (Ma trận tương tác):**
   - Bảng ma trận 2 chiều cho phép tăng/giảm số câu nhanh bằng nút bấm `+` / `-`.
   - **Gán vị trí câu chi tiết (Sub-items assignment):** Đối với câu Đúng/Sai ($1a, 1b, 1c, 1d$) và Tự luận, giáo viên có thể gán từng ý vào các bài học và mức độ khác nhau.
   - **Tự động cân đối (Auto-balance):** Thuật toán tối ưu hóa tự động điền số câu và điểm số bám sát chính xác $100\%$ tỉ lệ mục tiêu đã thiết lập.
   - **Khóa ô (Locking):** Khóa cố định các câu đã chỉ định trước khi chạy tự động cân đối cho phần còn lại.
6. **Bước 6: Bản đặc tả & Xuất tệp Word:**
   - Xem trước trực tiếp trên giao diện: Bảng khung ma trận, Bảng bản đặc tả chi tiết, Bảng kiểm tra 10 tiêu chí sư phạm.
   - Xuất tệp Word (.docx) nguyên bản, trình bày đẹp mắt, sẵn sàng in ấn nộp tổ chuyên môn và Ban Giám hiệu.

## 💻 3. Hướng dẫn chạy và phát triển dự án

### Yêu cầu môi trường
- **Node.js:** Phiên bản 18+ (khuyên dùng Node.js 20 hoặc 22)
- **NPM** hoặc **PNPM** / **YARN**

### Cài đặt dependencies
```bash
npm install
```

### Chạy chế độ phát triển (Development Server)
```bash
npm run dev
```
Trình duyệt sẽ tự động mở tại địa chỉ: `http://localhost:3000` (hoặc cổng hiển thị trên terminal).

### Biên dịch sản phẩm (Production Build)
```bash
npm run build
```
Thư mục `dist/` sẽ được tạo ra chứa mã nguồn HTML/JS/CSS đã tối ưu hóa, sẵn sàng triển khai lên Vercel, Netlify, Firebase Hosting, GitHub Pages hoặc máy chủ của nhà trường.

### Chạy thử bản Build
```bash
npm run preview
```
